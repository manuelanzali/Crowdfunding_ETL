## About our Analysis
● The goal of this was to extract excel files, transform them, and create several dataframes using Python, Pandas, and Python dictionary methods. We then created four CSV files and used the data to create an Entity relation diagrams (ERD) and a table schema. We finally used this data and exported it into a Postgres database.
